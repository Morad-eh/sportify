1. Introduction

Sportify est une application web de réservation de terrains de sport indoor. Elle permet aux membres de consulter les terrains disponibles, de réserver un créneau et de payer en ligne de manière sécurisée via Stripe.

L'application est accessible à l'adresse : https://ehsportify.pythonanywhere.com

2. Créer un compte

  1. Clique sur S'inscrire en haut à droite de la page
  2. Remplis les champs : prénom, nom, email, nom d'utilisateur, téléphone, mot de passe
  3. Clique sur S'inscrire
  4. Tu es automatiquement connecté et redirigé vers ton tableau de bord

3. Se connecter

  1. Clique sur Connexion en haut à droite
  2. Entre ton nom d'utilisateur et ton mot de passe
  3. Clique sur Se connecter

4. Consulter les terrains

  1. Clique sur Terrains dans la barre de navigation
  2. La liste de tous les terrains disponibles s'affiche (nom, localisation, prix à l'heure)
  3. Clique sur un terrain pour voir ses détails et ses créneaux disponibles

5. Réserver un créneau

  1. Sur la page de détail d'un terrain, consulte les créneaux disponibles
  2. Clique sur Réserver à côté du créneau souhaité
  3. Une page de confirmation s'affiche avec le récapitulatif (terrain, date, horaire, prix)

6. Payer en ligne (Stripe)

  1. Sur la page de confirmation, clique sur Procéder au paiement
  2. Tu es redirigé vers la page de paiement sécurisé Stripe
  3. Entre les informations de ta carte bancaire
  4. Clique sur Payer
  5. En cas de succès, un email de confirmation t'est envoyé et ta réservation apparaît dans ton tableau de bord
Pour tester en environnement de développement, utilise la carte de test Stripe : 4242 4242 4242 4242, date future, CVC quelconque.

7. Consulter ses réservations

  1. Clique sur Mon espace dans la navigation
  2. Ton tableau de bord affiche toutes tes réservations avec leur statut (Confirmée, Annulée)
  3. Les statistiques en haut indiquent le nombre total de réservations et l'année d'inscription

8. Modifier une réservation

  1. Dans le tableau de bord, repère une réservation avec le statut Confirmée et une date future
  2. Clique sur le bouton vert Modifier
  3. Une liste des créneaux disponibles pour le même terrain s'affiche
  4. Sélectionne un nouveau créneau en cliquant dessus
  5. Clique sur Confirmer la modification
La modification est gratuite et instantanée. Le créneau d'origine est automatiquement remis en ligne.

9. Annuler une réservation

  1. Dans le tableau de bord, clique sur le bouton rouge Annuler
  2. Une page de confirmation s'affiche avec les détails de la réservation
  3. Clique sur Confirmer l'annulation
  4. Le créneau est libéré et la réservation passe au statut "Annulée"
Le remboursement se fait sur demande par email à l'équipe Sportify. Seules les réservations à date future peuvent être annulées.

10. Gérer son profil

  1. Clique sur Mon profil dans la navigation
  2. Tu peux modifier : prénom, nom, email, téléphone
  3. Clique sur Enregistrer pour sauvegarder les modifications

11. Changer la langue

  1. Dans la barre de navigation, clique sur le sélecteur FR / EN / NL
  2. Sélectionne la langue souhaitée
  3. L'interface s'affiche immédiatement dans la langue choisie

Langues disponibles : Français, English, Nederlands

12. Supprimer son compte

  1. Accède à Mon profil
  2. Clique sur Supprimer mon compte
  3. Confirme la suppression sur la page suivante
  4. Ton compte et toutes tes données sont définitivement supprimés
Cette action est irréversible. Toutes les réservations associées au compte seront également supprimées.

13. API REST — Documentation (développeurs)

Sportify expose une API REST publique accessible à l'adresse /api/v1/. La documentation interactive est disponible sur https://ehsportify.pythonanywhere.com/api/v1/docs/.

Endpoint Méthode Description Auth
/api/v1/terrains/GETListe des terrainsNon
/api/v1/terrains/{id}/GETDétail d'un terrainNon
/api/v1/creneaux/GETCréneaux disponiblesNon
/api/v1/auth/register/POSTCréer un compteNon
/api/v1/auth/login/POSTConnexion + token JWTNon
/api/v1/reservations/GET/POSTMes réservationsJWT
/api/v1/reservations/{id}/PUT/DELETEModifier / AnnulerJWT
/api/v1/users/me/GET/PUTMon profilJWT
/api/v1/paiements/GETMes paiementsJWT
Les endpoints publics (terrains, créneaux) sont limités à 100 requêtes par heure sans authentification. Les endpoints protégés nécessitent un token JWT dans le header : Authorization: Bearer <token>
